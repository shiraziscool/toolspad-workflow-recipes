# Audit your agency’s first response to a client inquiry

Use this worksheet to find where new client inquiries wait for a useful reply. It works in a spreadsheet, a shared inbox, or a CRM. Start with five recent inquiries and review them with the people who cover the inbox.

## What to record

| Inquiry ID | Received | Automatic acknowledgement | First useful reply | Owner at receipt | Reason for delay | Next action and due date |
| --- | --- | --- | --- | --- | --- | --- |
| A-01 | Mon 09:10 | Mon 09:10 | Mon 10:05 | Inbox lead | — | Discovery call, Tue 11:00 |
| A-02 | Mon 16:40 | Mon 16:40 | Tue 10:15 | Unassigned | Inbox cover ended at 16:00 | Confirm scope, Tue 15:00 |
| A-03 | Tue 11:20 | — | — | Account lead | Awaiting an internal answer | Assign a reply owner, Tue 14:00 |
| A-04 | | | | | | |
| A-05 | | | | | | |

The filled rows are synthetic. Use a consistent time zone and record the actual times. A useful reply answers a question, asks for a missing detail, or offers a concrete next step. Keep automatic acknowledgements in their own column. For unanswered inquiries, leave the first-reply time blank and note how long each inquiry has been waiting.

## Review the five rows

1. **Compare like with like.** Record the elapsed time and whether the inquiry arrived during the hours you promise to cover. Keep weekend and after-hours cases visible.
2. **Look for a shared cause.** Group delays by reason, such as no owner, unclear handoff, missing context, or time outside coverage. If inquiries waited for a specialist, check whether a teammate could have sent a useful initial reply.
3. **Change one thing.** For the sample above, try assigning an inbox backup after 16:00 and giving that person a short list of common questions they can answer. Choose one change based on your own rows.
4. **Run the same check next week.** Use the same definition of a useful reply and the same business-hour rule. Compare unanswered counts and the median elapsed time among answered inquiries separately. Five rows can reveal an issue worth investigating. Use a larger sample to establish a trend.

Keep names, messages and customer records in your own workspace. Share an anonymized summary with teammates who need to see it.
